# 设计依据与边界（2026-11-20）

## 目标受众与核心心理

目标不是通过强制邀请操纵社交，而是提供有机会被人看见的、可重复验证的个人表现。以 **胜负、身份、炫耀** 为情绪三角：

1. 胜负：相同每日种子 + 微信关系链的前八名，能够直接比技术。
2. 身份：分段头衔、由连击驱动的立体冠冕变化，是可视化的荣耀。
3. 炫耀：结果页有排名式标题；用户自愿把真实成绩变成好友同题挑战。

## 核心行为闭环

- `选择战位 → 看敌人动作/外观 → 判断要闪躲还是反击 → 获得连击与临时荣耀 → 封存或继续冒险`。
- 58 秒周期缩短失败成本，支持即时重玩；不配置体力等待，避免限制技术练习。
- 金色敌人可反击，暗红刺甲敌人须避开，绿色珠宝自动收取。三种轮廓及配色不同，配合音效和视觉反馈。
- 越贪连击临时分数越高，被击中时损失越大：不依赖概率开箱制造刺激。
- 规则确定性，所有人可在同一日关卡比较；分享使用种子，而不是无法解释的“关卡编号”。

## 封存风险示例

累计 4,000 未封存荣誉，击中刺甲则会失去 `ceil(4,000 × 62%) = 2,480`，留下 1,520；及时点击封存则安全保留 4,000，但连击归零、按钮冷却 3.4 秒。回合结束时剩余未封存的 4,000 只按 2,800 结算。

## 创新主张与现实边界

可辨认的差异化是 **角色冠冕随连续反击改变 + 当场主动止盈的风险管理 + 微信关系链同题竞赛** 的组合。单独的三战位切换、反击、排行榜并非新机制，不以营销说法宣称“首创”。

本工程是有完整循环的首个可测试版本，尚未有用户留存/付费/裂变数据。必须用真实受试者检验：前 30 秒理解率、连续三局重玩率、每局封存次数、分享率、场均完美反击次数、帧时间和崩溃率，再决定是否扩大内容。
