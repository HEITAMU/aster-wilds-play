# 窃冠者 · THE CROWN THIEF

**微信小游戏 / Cocos Creator 3.8.8 / 竖屏 3D**

> 项目状态：完整首轮游戏循环、原生 Cocos 3D 模型生成、原创音乐与音效、微信好友排行接口、定向挑战分享、激励视频与 banner 广告位均已编写。静态源码验证与玩法规则单元测试通过；**没有在本环境运行 Cocos Creator 编辑器、微信开发者工具或真机，所以不宣称已完成平台构建或审核。**

## 概念

你不是在跑道上收集普通金币，而是在一场 58 秒的王庭决斗中**偷取他人的冠冕**。

每次成功反击，临时荣耀增加，头上的立体王冠也会长得更华丽。只要在被打中之前点击「封存荣耀」，就能把荣誉锁进安全分数；如果一直贪连击，失误会使**未封存分数损失 62%**。终场会以七折计算剩余未封存分。风险与收益完全来自玩家自己的判断。好友挑战使用同种子、同波次。

### 操作

- 手机左右滑动或点击左右侧移按钮，切换三个战位。
- 对手走到身前时点「精准反击」；越接近合适时机分越高。红刺敌人应躲开，不可反击。
- 珍宝经过所在战位会自动拾取。
- 点「封存荣耀」锁住当前战利品，代价是清空连击，且有 3.4 秒冷却。
- 电脑开发调试：`A` / `←` 向左、`D` / `→` 向右、`空格` 反击、`B` 封存。

## 美术及内容交付

没有平移单张贴图当作角色动画，也没有使用 Cube / Sphere / Cylinder 拼装角色。`Art.ts` 生成带顶点法线的雕塑曲面：褶皱披风、雕花盔甲、瓷质面具、金属冠冕、手套、蔷薇花瓣、连续织锦地面、装饰柱、雕花拱顶，以及可分部件转动的人物。主角和对手都是由曲面网格渲染、受两盏方向光照明的真实 3D 对象；角色待机和反击反馈由 Node 变换驱动。音乐与 7 个音效独立合成，是本工程原创素材。

**画质边界**：这是原创程序建模的首版风格化 3D 美术，不等同于经过专业角色建模、绑定、特效和长期迭代的商业级美术。建议手机实测后优化性能、特效与动作关键帧。

## 打开工程

1. 安装 **Cocos Creator 3.8.8**，以项目根目录打开（包含 `package.json` 的目录）。首次打开允许编辑器导入资源与建立 `temp/library` 缓存。
2. 打开 `assets/scene/Entry.scene`；在浏览器预览。无需本地服务、数据库或账户才能玩完整单局。
3. 在菜单 `项目 → 构建发布` 选择微信小游戏，填写你自己的 **小游戏 AppID**、**Portrait（竖屏）**。构建后运行微信开发者工具。
4. 在项目根目录执行 `node tools/install-wechat.mjs build/wechatgame`，将独立微信好友榜代码写入发布目录，并将 `game.json` 指向它；**每次重新构建以后再运行一次**。
5. 在 `assets/scripts/config.ts` 填入**真实且已获准启用**的 `adunit-...` 广告位 ID（激励视频 / banner）。空值时游戏照常运行，但不会展示假广告。
6. 在微信开发者工具用两个以上真实、可访问关系链的微信账号核验分数上传、好友榜、转发挑战与广告回调，再提交微信审核。

## 社交公平性

- 按北京时间日期算每日种子，每位玩家面对同一顺序敌阵；赛道不会从广告或分享获得改变。
- `wx.setUserCloudStorage` 上传当天最佳数字分数；好友榜仅在开放数据域调用 `wx.getFriendCloudStorage`、在 `sharedCanvas` 绘制，**不传输好友数据回主域**。
- 结算玩家主动点击「晒出战绩」时，通过 `wx.shareAppMessage` 分享 `seed / target / date`；打开分享卡进入同种子挑战。**分享没有奖励，也不作为继续游戏的前提。**
- 装饰碎片不提高分数能力；激励视频仅在玩家自愿完整观看并收到 `isEnded: true` 后额外发放一次本局装饰碎片。
- 由于 `wx.setUserCloudStorage` 属于客户端接口，**此实现没有服务端反作弊**。若开放更严肃的赛事/奖金，请增加微信云开发校验服务，不要把当前版本的好友榜误称为可信全服排行榜。
